# 通用权限工作台原型

入口：[general-permission-studio.html](general-permission-studio.html)

单个 HTML，CSS、交互逻辑、示例数据和图标全部内嵌；可直接用浏览器打开，无需安装依赖。图标沿用项目 Ant Design Icons（MIT）。

## 建议讨论路径

1. **权限总览**：了解调用应用、业务主体、映射模型、资源策略与执行范围的关系。
2. **身份模型**：切换 CRM / ERP。两套不同物理表结构映射为同一逻辑语义，身份目录与业务库独立。
3. **主体目录**：观察两个应用中同名 `user-001` 的不同业务身份，以及无角色/源账号停用的情况。
4. **数据授权**：调整主体绑定、字段可读/筛选/脱敏、行规则及资源字段/主体属性映射；保存草稿后预检结果不变，发布后重新预检生效。
5. **权限验证**：演示外部撤权、错误签发方、过期断言、范围限制、缺失属性和脱敏字段筛选拒绝；查看治理后的示例行与参数化计划。
6. **讨论清单**：记录模型复用、多策略合并、外部失效检测和首批范围的倾向与备注，导出 JSON 留档。

## 演示行为与范围

- 应用配置在点击保存后参与预检；模型/策略草稿可自动暂存，正式版本只有确认发布后改变。
- 模型与策略修改会保留在浏览器 localStorage；“重置演示”恢复初始示例。讨论选择仅为倾向，不能修改授权算法或代表已确认合同。
- 支持单条主体策略、本人与组织行范围、字段投影/筛选/脱敏和返回行数上限；新增实体/关系可保存在草稿中用于讨论，当前模拟解析器不支持发布这些扩展。
- 预检完全在浏览器内计算。无真实认证、网络调用、数据库连接、SQL 解析/执行；请求示例没有凭据。不要输入真实密钥或业务数据。
- 多策略合并、服务主体完整配置、外部提供者、Wiki/数据集/历史执法属于待讨论或后续实现；页面明确标记边界。
- 示例中的表名、角色名和规则都是夹具配置，不是拟落地的领域模型枚举。
