# 数据集与对话式 DataWiki：第二轮实现

> 后续验收与适配更新见 [2026-10-13 验收记录](release-acceptance-20261013.md)及 [P2 适配修订](p2-permission-adaptation-20261013.md)；本文原验收结论保留当时语境。

> 2026-10-12；用户六项反馈已授权实现。原 P2 仍指权限执法，本轮不切换 ENFORCED。已实现，验证结果见本文末尾。

## 1. 页面与交互

- 全局菜单、DataWiki 目录、右侧信息可独立收缩；目录/信息保留按钮恢复，状态在浏览器保存；专注编辑一次收起辅助栏，不卸载编辑表单。
- 同步产生 STRUCTURE 类型的纯结构发布页，不包含人工语义，成功后立即可被检索。TABLE 类型的业务说明仍独立编辑；无业务内容的新表显示“结构已同步 · 业务说明待补充”，不计入待发布清单。
- 待发布/待复核清单支持选中项和当前目录范围的统一发布。预览汇总后一次确认，每页校验版本、独立原子事务，失败项保留草稿并明确回执。批次 ID、时间与每项结果保存至审计，可在发布记录查看。
- 数据集页配置名称、说明、启停、成员数据库、成员别名、具体表范围及 Wiki 选择。选择当前全部表也是固定清单，后续同步不能静默扩大范围。
- DataWiki 顶部选择数据库/数据集；继承成员库表知识，在数据集空间维护跨库指标、术语和关联规则。共享库表说明修改影响所有继承者。
- 数据库可创建多个业务文档空间、明确设置全局默认。基础库表/结构知识始终继承；选择替代空间时不会继续继承基础空间内的旧业务文档。数据集成员可继承默认或显式选定同库空间，不隐式修改全局默认。
- AI 对话选择数据库或数据集，模型默认值由服务端解析。历史会话恢复范围与有效模型，范围、知识绑定或模型变化要求新会话。

## 2. 对话维护知识

DataWiki 的“AI 补充知识”使用独立的 KNOWLEDGE 会话。默认编辑当前数据库/数据集知识范围，活动表或文档只是关注上下文；可显式收窄到固定选中页面及本会话新建文档。模型工具只读结构与 Wiki，并创建/修改草稿；不能执行业务 SQL，也不能发布。

工具：list_knowledge_drafts、read_knowledge_draft、find_knowledge_objects、apply_knowledge_updates、create_knowledge_document。批量补充每次最多20页，每页版本检查。用户原话片段记录为 USER_PROVIDED（仍待人复核），无可验证片段的推断记录为 AI_SUGGESTED；不把模型声称“用户确认”当作授权。

页面展示字段前后值、来源及本次变更清单。后续对话继续修正草稿。用户一次确认选中项后，服务端只发布本会话实际生成且仍在当前范围内的草稿；冲突逐项返回。

## 3. 默认模型

meper_model_default 单例指针确保只有一个默认配置。模型设置可“设为默认”，必须启用。默认绑定和停用/删除串行化；先切换默认，再停用/删除原模型。不静默失败转用另一模型。

首次调用：明确选择模型 > 系统默认。已有会话未显式选择时保留该会话的有效模型，不因系统默认变化无提示切换。无默认/无明确选择则返回配置提示。启动仍不依赖 apiKey。

## 4. 跨库分析

DatasetService 签发 AnalysisScope，包含成员别名、数据库类型、精确资源范围与知识分区。指纹由配置版本、成员资源和有效 Wiki 绑定生成；每次工具调用重新检查。

数据库模式下，已配置 catalog 的 MySQL 限定该库的查询、结构发现及 Wiki 读取；实例级空 catalog 连接保留其显式配置范围。数据集可显式选择多个 catalog 的具体表。PostgreSQL/SQL Server/Oracle 使用连接内 schema。

Agent 经 AnalysisService 调用 WorkbenchService；QueryScopeValidator 用对应方言 AST 校验一条 SELECT 的全部表源、JOIN、子查询、CTE，拒绝无法解析、越界、写入子语句、INTO/FOR UPDATE、动态表源与不受支持函数。非限定表会用已验证命名空间限定，执行对象与验证对象一致。结果仍显式为 BOOTSTRAP_ADMIN_UNRESTRICTED；数据集范围检查不等于 P2 主体/字段策略执法。

本轮的 ResultWorkspace 保留完整受限查询结果，并返回 handle 与最多30行样本。固定算法：LEFT/INNER 关联（基数检查、NULL 不互相匹配）、BigDecimal 新列计算、分组求和/计数；不用模型文本做金额累计，不运行任意代码。源结果截断拒绝合并/汇总。每库最多200行，工作区最多24个结果、5000行单结果和累计100万字符；大问题先在库内聚合。

结果回执携带执行记录、成员来源、查询时间、截断状态和执法标记；UI 可展开样本。不同库查询不承诺一致事务快照。统一联邦 SQL 引擎不属于本轮，多个连接已可按上述路径真实分析。

## 5. 知识范围与会话

数据集虚拟目录 `/sources/{alias}/...` 与 `/dataset/...`。本轮有效发布版本清单在工具创建时固定；按实际发布版本的资源绑定做过滤，不能使用后来修改的草稿绑定证明旧版本可见。读取重新检查结构有效性和范围。

meper_chat_scope 保存主体、范围类型/ID/指纹、有效模型、用途、空间及命名空间。分析与知识编辑历史不能混用，不能把单库历史带入另一数据集。最近窗口仍为20条，序号按持久化最大值递增，重启后可回源。工具每轮共享40次调用和64000字符预算。

当前 WikiAccess 仅允许已认证引导管理员。多用户上线仍需 P2 的主体/字段过滤与历史再授权，本轮不声称已完成该权限阶段。

## 6. 存储与 API

只追加 V8，保留 V1–V7。V8 新增 dataset/member、wiki_space/default、model_default、chat_scope、wiki_edit_origin；迁移补独立外键索引后替换旧唯一键，历史 Wiki 保留。权限迁移接实际最新版本，当前下一号为 V9。

- `/api/datasets`：列表、详情、创建、版本化更新；`/{id}/scope` 签发当前范围。
- `/api/datasets/{id}/wiki`：继承页面/对象、分区搜索和统一发布。
- `/api/wiki-spaces/{id}`：草稿、发布、历史、读取、批次记录。
- `/api/datasources/{id}/wiki/spaces` 与 `/default-space`：文档空间与全局默认；原数据库 Wiki API 保留。
- `/api/model-providers/{id}/default`：明确设置默认模型。
- `/api/agent/chat/stream`：scopeType=DATABASE/DATASET，scopeId；providerId 可省略。
- `/api/agent/chat/knowledge/stream`、`/knowledge/publish-batch`：对话编辑与用户统一发布。
- `/api/agent/chat/sessions/{id}/context`：恢复有效上下文；`/knowledge/reference`：范围约束下读取引用版本。

## 7. 人工验收

1. 收缩全局菜单、知识目录和右侧信息，修改字段后验证展开仍保留编辑。
2. 同步新库：结构即刻可检索，新空白业务表不再要求逐项发布。
3. 修改多张表/文档，清单选中后统一发布；另一个窗口修改其中一项，确认冲突项不覆盖，发布记录能找到批次。
4. 配置默认模型，打开 AI 补充：描述金额单位、粒度与状态，一段对话补充多个草稿；后续对话修正，统一确认发布。
5. 创建含 MySQL 与 PostgreSQL 的数据集，选定订单与退款表，配置别名及成员 Wiki。
6. 在数据集 Wiki 定义净收入与退款关联，AI 对话选该数据集，分库查询后关联、计算、汇总；检查来源和180元测试结果。
7. 测试重复退款键与截断数据：声明基数不符或结果不完整时必须拒绝，不能静默重复累计。
8. 从数据集移除表或更改默认 Wiki：旧范围指纹失效，需要新会话；越界 SQL、旧编辑历史串到分析会话应被拒绝。
9. 默认模型不能直接停用/删除；必须先明确设置另一个默认。旧会话不能无提示切换模型。

## 10. 数据库文档的领域归属

数据库下的知识文档随该数据库配置的默认文档空间加载和创建；空间只能属于该数据库。DataWiki明确展示数据库名称、当前空间以及「数据库默认」或「临时查看」状态。新建文档说明保存归属，页面信息展示数据库/数据集归属。数据源列表新增「知识配置」入口，可直接配置该数据库默认空间。

数据集继承成员数据库默认空间（或成员显式指定的同库空间），跨库规则、统一指标与术语归属数据集专属文档。临时浏览另一个空间不改变数据库配置，必须显式设为默认；未迁移、合并或自动改写现有文档。


## 11. 已开放编辑能力的闭环补齐

- `focusPageIds` 提供经服务端校验的关注页面，不决定授权范围、不改变会话指纹；`pageIds` 仍用于用户显式收窄范围。两者都不能越出所选数据库/数据集。
- 浮窗默认选择完整知识范围。用户选择限定页面时保存固定清单，浏览其他页面不会偷偷扩大范围；切换编辑范围开启新会话。
- 创建文档单独记录会话创建来源。固定页面会话后续轮次将自己的新建文档与当前可见范围取交集，不纳入其他会话创建的页面；范围变化仍按既有规则要求新会话。
- 修改标题与关联资源均记录前后差异和会话来源，单独修改也可进入本会话统一发布。浮窗按页面累积多轮字段差异，同一字段保留最初值和最新值，避免后一轮覆盖整页变更清单。表说明的结构绑定不可由语义编辑工具修改。
- 非默认但属于本数据库的编辑文档空间，用户确认发布时也纳入相同的知识分区校验。
- 保持原有工具集合。未增加历史恢复、停用/启用、知识空间创建、默认Wiki配置或模型自主发布工具。
