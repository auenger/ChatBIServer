# 占比分析

- 少量非负分类数据展示组成比例，选择 `pie`；设置 `innerRadius:0.6` 可展示环图。
- 先获取真实聚合数据，每行字段为 `category`（类别）、`value`（原始数值，非格式化的百分比字符串）。
- 负数或合计为零不能画饼图，应改为表格说明。类别较多时优先条形图；需要“其他”分类时通过查询获得，不能编造。
- 样本、Top N 或截断结果的占比仅代表该范围，不得称为全量占比；明确分母和单位。
- 返回 Markdown 表格、图表与简要中文结论。图表使用 `GPT-Vis` 代码块，内容是 JSON：

```GPT-Vis
{"type":"pie","title":"区域销售额占比","innerRadius":0.6,"data":[{"category":"华东","value":120},{"category":"华南","value":80}]}
```

示例数据仅用于说明格式，实际回答必须替换为查询结果。空结果或查询失败时不生成图表。
