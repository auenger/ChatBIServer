# 趋势分析

- 用于按日、月、年变化的数据，选择 `line`；累计或总量展示可选择 `area`。
- 先查询真实聚合数据，按时间排序；每行字段为 `time`（时间标签）、`value`（数值），可带 `group`（分组名称）。
- 明确时间范围、单位；缺失数据不可自行补零。结果截断或只为样本时必须在解读中说明。
- 返回 Markdown 表格、图表与简要中文结论。图表使用 `GPT-Vis` 代码块，内容是 JSON：

```GPT-Vis
{"type":"line","title":"月度销售趋势","axisXTitle":"月份","axisYTitle":"销售额（元）","data":[{"time":"2026-01","value":120},{"time":"2026-02","value":180}]}
```

示例数据仅用于说明格式，实际回答必须替换为查询结果。空结果或查询失败时不生成图表。
